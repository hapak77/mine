# 🚗 Telegram-бот «ПДД без зубрежки: Взлом билетов»

Продакшн-система для подготовки к теоретическому экзамену ГИБДД (категории A, B, M) с геймификацией («жизни»), умным тренажером по 5 модулям, симулятором экзамена, реферальной программой, приемом платежей и Telegram-админкой.

---

## 🛠 Стек технологий и архитектура

* **Язык и фреймворк:** Python 3.11+, `aiogram 3.15`
* **Базы данных:**
  * **PostgreSQL 16:** основное хранилище (пользователи, билеты, ошибки, платежи, рефералы).
  * **Redis 7:** хранилище FSM-состояний и кэш сессий.
* **Связь с Telegram API:** Поддержка **Webhooks** через обратный прокси Nginx (с SSL/HTTPS) и режим **Long Polling** для локальной разработки.
* **Инфраструктура:** Полная контейнеризация через `docker-compose.yml`.
* **Безопасность и логирование:** Все секреты изолированы в `.env`. Ошибки уровня `ERROR/CRITICAL` автоматически форматируются и пересылаются в приватный админский чат.
* **База знаний:** Вшитая база из всех 800 официальных вопросов с разбивкой по темам, официальными ответами, живыми комментариями Инструктора и мнемоническими лайфхаками.

## Примечание к этому репозиторию

Точка входа — `main.py` в корне (её запускает Dockerfile). Папка `/opt/pdd_bot` ниже — каталог на VPS, а не вложенная папка репозитория.

`data/parsed_tickets.json` здесь — учебная выборка с флагом `"sample": true`, а не официальные 800 вопросов ГИБДД. Полный банк кладётся в этот же файл без правок кода. Формат: объект с массивом `questions` (также принимается список или `tickets[].questions`). У вопроса нужны `id`, `module` (1–5), `block`, `text`, `answers`, `correct` (индекс с нуля). Необязательные поля: `ticket`, `number`, `comment`, `mnemonic`, `image`, `qualification`. Читаются и синонимы `question`, `options`, `correct_answer`, `explanation`, `topic`.

`data/master_pdd_guide.pdf` бот отправляет командой `/start`.

Токен `PAYMENT_PROVIDER_TOKEN` из `.env.example` включает режим **dry-run**: тариф записывается без счёта и без списания. Боевой токен включает ЮKassa через Telegram Payments (токен с `:TEST:` — тестовый контур Telegram, не боевые деньги). `ENABLE_TELEGRAM_STARS=true` добавляет оплату звёздами; в dry-run звёзды тоже не списываются.

`pip install -r requirements.txt` в чистом виде не сходится: `aiogram==3.15.0` требует `aiohttp<3.11` и `pydantic<2.10`, а файл фиксирует `aiohttp==3.11.0` и `pydantic==2.10.0`. Dockerfile ставит эти зафиксированные версии явно. Запуск по инструкции — через `docker compose`.

## 🚀 Быстрый старт на сервере (VPS)

### Шаг 1. Клонирование и настройка окружения

1. Загрузите файлы проекта на VPS-сервер (в папку `/opt/pdd_bot`).
2. Перейдите в каталог проекта и создайте рабочий файл конфигурации:
   ```bash
   cd /opt/pdd_bot
   cp .env.example .env
   nano .env
   ```
3. Заполните обязательные параметры:
   * `BOT_TOKEN` — токен вашего бота от `@BotFather`.
   * `ADMIN_IDS` — ваш цифровой Telegram ID (узнать можно в `@userinfobot`).
   * `ADMIN_CHAT_ID` — ID группы/канала для отправки уведомлений об ошибках (необязательно).
   * `POSTGRES_PASSWORD` и `REDIS_PASSWORD` — придумайте надежные пароли.

---

### Шаг 2. Запуск в режиме Long Polling (самый простой старт)

Для быстрого тестирования без необходимости настраивать домен и SSL:
1. В `.env` убедитесь, что стоит:
   ```env
   USE_WEBHOOK=false
   ```
2. Запустите контейнеры в фоновом режиме:
   ```bash
   docker compose up -d --build
   ```
3. Проверьте запуск сервисов:
   ```bash
   docker compose ps
   docker compose logs -f bot
   ```
   *При первом запуске бот создаст таблицы в PostgreSQL и загрузит вопросы из `parsed_tickets.json`. В репозитории это учебная выборка (`"sample": true`); полный банк подменяется тем же файлом, см. примечание выше.*

---

### Шаг 3. Запуск в режиме Webhooks (для высоких нагрузок)

1. Привяжите доменное имя (например, `bot.yourdomain.com`) к IP-адресу вашего VPS.
2. Получите бесплатный SSL-сертификат с помощью Certbot:
   ```bash
   apt-get update && apt-get install -y certbot
   certbot certonly --standalone -d bot.yourdomain.com
   ```
3. Скопируйте сертификаты в папку `nginx/ssl`:
   ```bash
   mkdir -p nginx/ssl
   cp /etc/letsencrypt/live/bot.yourdomain.com/fullchain.pem nginx/ssl/
   cp /etc/letsencrypt/live/bot.yourdomain.com/privkey.pem nginx/ssl/
   ```
4. В файле `.env` укажите:
   ```env
   USE_WEBHOOK=true
   WEBHOOK_DOMAIN=https://bot.yourdomain.com
   WEBHOOK_SECRET=любая_случайная_строка_символов
   ```
5. В `nginx/nginx.conf` раскомментируйте блок `server { listen 443 ssl ... }` и укажите ваш домен.
6. Перезапустите контейнеры:
   ```bash
   docker compose up -d --build
   ```

## 🎮 Механики и воронка бота

1. **Онбординг:**
   * По команде `/start` бот присылает приветствие (и видео-кружок Инструктора, если заполнен `WELCOME_VIDEO_NOTE_ID`), автоматически дарит PDF-шпаргалку `master_pdd_guide.pdf` и предлагает пройти входной квалификационный тест из 3 сложных вопросов.
   * На каждый неправильный ответ бот моментально выдает подробный комментарий с мнемоникой и лайфхаком.
   * После 3-го вопроса срабатывает Paywall с презентацией тарифов курса.

2. **Жизни и геймификация:**
   * У бесплатных пользователей есть запас в **5 жизней** (`❤️❤️❤️❤️❤️`).
   * Каждая ошибка в тренажере отнимает 1 жизнь.
   * При нуле жизней прохождение блокируется. Жизни восстанавливаются автоматически: **+1 жизнь каждые 3 часа** (бот присылает пуш).
   * Либо пользователь может мгновенно восстановить все 5 жизней, отправив свою реферальную ссылку другу.

3. **Режимы обучения:**
   * **🚗 По темам:** выбор любого из 5 ключевых модулей (Перекрестки, Регулировщик, Обгон/Стоянка, Знаки, Медицина).
   * **⚡️ Марафон:** последовательное решение всех 800 вопросов с сохранением прогресса.
   * **🛠 Работа над ошибками:** интеллектуальный пул, формируемый исключительно из вопросов, на которых пользователь споткнулся ранее.
   * **🎯 Симулятор экзамена:** реальный экзамен ГИБДД — 20 минут, 20 случайных вопросов, +5 дополнительных вопросов за ошибку из того же блока.

4. **Встроенная админка (`/admin`):**
   * **📊 Статистика:** просмотр общего числа регистраций, активных пользователей, конверсии в оплату и суммы выручки.
   * **📥 Excel-отчет:** мгновенная генерация файла со списком всех пользователей, их тарифами, балансом жизней и историей платежей.
   * **📢 Рассылки:** возможность отправить сообщение с кнопками всем пользователям или отфильтровать только бесплатных (для дожима в покупку).
